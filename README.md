# Netflix Data Cleaning & Preprocessing — Internship Task 1

This project focuses on **data cleaning and preprocessing of the Netflix Movies and TV Shows dataset** as part of a Data Analyst Internship Task.

The project uses **Microsoft Excel** to identify, analyze, and address common data-quality issues such as missing values, duplicate records, inconsistent text formats, incorrect data placement, date formatting, and data-type validation.

## Key Activities

* Analyzed the raw Netflix dataset and its overall structure
* Identified and assessed missing values
* Checked for duplicate records and duplicate `show_id` values
* Investigated inconsistent and misplaced values
* Corrected duration values incorrectly stored in the `rating` column
* Standardized date formats in `date_added`
* Checked and standardized categorical/text values
* Validated data types and data quality
* Created before-and-after quality checks
* Documented cleaning decisions and methodology

## Dataset

**Netflix Movies and TV Shows**

* 8,807 records
* 12 columns
* Includes information such as title, type, director, cast, country, date added, release year, rating, duration, genres, and description.

## Tools Used

* Microsoft Excel
* Excel Filters
* Remove Duplicates
* Conditional Formatting
* COUNTBLANK / COUNTIF
* TRIM
* Text to Columns
* Data Validation

## Key Learning

This project demonstrates that effective data cleaning is not simply about deleting missing or duplicate records. It requires **understanding the data, identifying the cause of quality issues, making appropriate cleaning decisions, and validating the final dataset before analysis**.

The cleaned dataset is intended to serve as a reliable foundation for further analysis and visualization.
